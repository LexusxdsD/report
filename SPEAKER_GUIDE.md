## Распределение по докладчикам

### 🎤 Глеб (Логинов Г.) - Разделы 1-3 (~10 минут)

**Ответственность:** Введение в тему, объяснение основ пентестинга и терминологии

**Слайды:**
- **Слайд 1:** Титульный слайд (представление команды)
- **Слайд 2:** Введение - Безопасность в цифровую эпоху
- **Слайд 3:** Что такое тестирование на проникновение (пентестинг)?
- **Слайд 5:** Ключевая терминология - Глубина и подходы

**Темы для освещения:**
1. **Введение. Тестирование безопасности**
   - Важность безопасности в современном мире (статистика IBM: $4.45M)
   - Что такое тестирование безопасности
   - Виды тестирования: Vulnerability Assessment, Security Audit, Risk Assessment, Security Scanning, Penetration Testing
   - Почему это критически важно

2. **Тестирование на проникновение: основы**
   - Определение пентестинга
   - Отличия от других видов тестирования
   - Зачем нужно компаниям
   - Краткая история (1960-е - наши дни)

3. **Основные понятия и терминология**
   - Pentest vs Vulnerability Assessment vs Red Teaming
   - Белый, серый и чёрный ящик (white/grey/black box)
   - Ethical hacking и легальный статус
   - Scope, Rules of Engagement, Bug Bounty

**Ключевые моменты:**
- Начните энергично, привлеките внимание аудитории
- Используйте статистику для демонстрации важности темы
- Объясните базовые концепции доступным языком
- Плавно переходите к Кириллу после раздела о терминологии

---

### 🎤 Кирилл (Кульбеда К.) - Разделы 4-6 (~10 минут)

**Ответственность:** Методологии, детальные этапы пентестинга и инструменты

**Слайды:**
- **Слайд 4:** Методологии - Систематический подход к взлому
- **Слайд 6:** Этапы пентестинга
- **Слайд 7:** Разведка - Пассивная и активная
- **Слайд 8:** Сканирование уязвимостей
- **Слайд 9:** Эксплуатация уязвимостей (SQL, XSS)
- **Слайд 10:** Повышение привилегий и закрепление
- **Слайд 11:** Документирование и отчётность
- **Слайд 12:** Арсенал инструментов

**Темы для освещения:**
1. **Методологии пентестинга**
   - OWASP Testing Guide (для веб-приложений)
   - PTES (универсальный стандарт, 7 фаз)
   - NIST SP 800-115 (для госсектора)
   - Сравнение и выбор подхода

2. **Этапы тестирования на проникновение**
   - **5.1. Разведка:** Пассивная (OSINT) и активная (сканирование портов)
   - **5.2. Сканирование и перечисление:** Nmap, Nessus, OpenVAS
   - **5.3. Получение доступа:** SQL-инъекции, XSS, CSRF + пример Equifax 2017
   - **5.4. Поддержание доступа:** Бэкдоры, руткиты, privilege escalation + пример Target 2013
   - **5.5. Заметание следов и отчётность:** Структура отчёта (Executive Summary, методология, находки, рекомендации)

3. **Инструменты пентестера**
   - Kali Linux (600+ инструментов)
   - Metasploit Framework
   - Burp Suite (для веб-приложений)
   - Wireshark (анализ трафика)
   - Social Engineering Toolkit (SET)
   - Реальный пример использования Metasploit

**Ключевые моменты:**
- Это самая техническая часть - объясняйте сложные концепции просто
- Используйте реальные примеры (Equifax, Target) для демонстрации рисков
- Покажите взаимосвязь между этапами
- Подчеркните важность систематического подхода
- Передайте эстафету Диме после раздела об инструментах

---

### 🎤 Дима (Филипчук Д.) - Разделы 7-10 (~10 минут)

**Ответственность:** Типы пентестинга, правовые аспекты, карьера и заключение

**Слайды:**
- **Слайд 13:** Различные типы тестирования
- **Слайд 14:** Заключение и будущее пентестинга

**Темы для освещения:**
1. **Типы пентестинга**
   - **7.1. Тестирование веб-приложений:** OWASP Top 10 + пример British Airways 2018
   - **7.2. Тестирование сетевой инфраструктуры:** пример Colonial Pipeline 2021
   - **7.3. Тестирование мобильных приложений:** пример приложений для знакомств 2018
   - **7.4. Социальная инженерия:** пример Twitter 2020
   - **7.5. Физический пентест:** пример дата-центра финансовой корпорации 2018

2. **Правовые и этические аспекты**
   - Необходимость письменного разрешения
   - Законодательство: УК Беларуси (ст. 349-352), УК РФ (ст. 272-274), CFAA (США)
   - Этический кодекс пентестера
   - Responsible Disclosure
   - Пример юридических проблем

3. **Карьера в пентестинге**
   - Сертификации: CEH, OSCP, GPEN
   - Зарплаты ($70K-$200K+ в США)
   - Bug Bounty платформы: HackerOne, Bugcrowd, Synack
   - Вдохновляющий пример: "santuber" - $1M+ через Bug Bounty

4. **Заключение**
   - Важность регулярного пентестинга
   - Тренды: облачные сервисы, IoT, AI/ML
   - Пентестинг как неотъемлемая часть безопасной разработки ПО
   - Призыв к действию для компаний и будущих специалистов

**Ключевые моменты:**
- Используйте много реальных примеров (5 крупных инцидентов)
- Подчеркните практическую применимость знаний
- Вдохновите аудиторию историей успеха "santuber"
- Завершите на позитивной ноте о будущем индустрии
- Сделайте сильное заключение, суммируя ключевые идеи

## Общие рекомендации для всей команды

### Перед презентацией:
1. ✅ Изучите свой раздел в README.md
2. ✅ Просмотрите соответствующие слайды в папке "Фото доклада"
3. ✅ Прорепетируйте переходы между докладчиками
4. ✅ Проверьте общее время (должно быть ~30 минут)
5. ✅ Подготовьте ответы на возможные вопросы по своему разделу

### Во время презентации:
- 🎯 Говорите чётко и уверенно
- 🎯 Смотрите на аудиторию, а не только на слайды
- 🎯 Используйте примеры для иллюстрации концепций
- 🎯 Следите за временем
- 🎯 Делайте плавные переходы между докладчиками
